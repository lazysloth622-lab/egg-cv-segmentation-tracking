Dataset and split

110 originals; 88 development / 22 held-out evaluation; zero declared visual-family crossings. Evaluation groups: G06, G07, G08, G09, G10, G12, G13. The conservative 58-image kitchen family remains development-only, limiting held-out multi-egg/scene diversity. Visual grouping cannot prove physical-egg/session independence.

Methods

Pretrained SAM ViT-B with recorded per-egg prompts and human review created visible-egg reference masks; no SAM training. Classical inference used only original pixels and the selected configuration. 16 configurations were compared on DEV only; C08_grabcut_center was selected by macro DEV IoU. The algorithm was frozen before held-out reference pixels were read.
